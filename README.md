# RJ Photography Portfolio Website

A modern, responsive photography portfolio website built with React and Firebase.

## Features

- Responsive design that works on all devices
- Photo gallery with category filtering
- About Me section
- Contact form
- Admin panel for photo management
- Social media integration

## Tech Stack

- React.js
- Firebase Hosting
- CSS3 with modern styling
- Responsive design principles

## Setup Instructions

1. Clone the repository:
```bash
git clone git@github.com:AlexHusseini/RJWebsite.git
cd RJWebsite
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Build for production:
```bash
npm run build
```

5. Deploy to Firebase:
```bash
firebase deploy
```

## Admin Access

The admin panel can be accessed through the "Site Admin" link at the bottom of any page. 
Contact the developer for admin credentials.

## Development

- `src/components/` - React components
- `src/auth/` - Authentication utilities
- `public/images/` - Image assets
